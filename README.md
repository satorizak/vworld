# vworld - 3D Virtual World

A multiplayer 3D virtual world built with Three.js and PHP.

## Play the World

Visit: **https://zaktree6.github.io/vworld/**

This link always works and automatically redirects to the current server.

## Starting the World (for admin)

1. Open the Codespace on the `vworld` repo
2. Run `./start-world.sh`
3. Done! The world URL is published automatically to GitHub Pages.

## If the Codespace is deleted

Same as above — just create a new Codespace from this repo and run `./start-world.sh`. Everything installs automatically.

## Features

- Multiplayer avatars with name labels
- Chat box
- Billboard image uploads
- Own Overlook platforms (auto-cleanup when player leaves)
- Mobile and desktop support
